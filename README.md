# R-ESUME（留学生向け自動履歴書作成システム）

R-SERIES の1つ。留学生が、厚生労働省の履歴書様式例に沿った履歴書を画面で作り、印刷／PDF に保存できるシステム。

- フロント：GitHub Pages（`frontend/`）
- バックエンド：Google Apps Script の Webアプリ（`backend/`）
- データ：Googleスプレッドシート「R-esume_留学生向け自動履歴書作成システム」
- お支払い：銀行振込だけ（980円・税込・1年間）

要件と進み具合は、Claude の「Rickyエリア」プロジェクトの `r-esume-requirements.md` と `r-esume-progress.md` にあります。
